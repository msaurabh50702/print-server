Chrome only installs apps from secure (https) sites. This page was opened over plain http, so it can only add a shortcut. Do this once on each phone:

    iPhone / iPad

    Open the download in Safari and allow the profile. Then Settings → General → VPN & Device Management → install the profile. Finally Settings → General → About → Certificate Trust Settings → turn it on.
